RangeSlider thumb interaction showcase

Experimental restyle of the existing Kendo k-slider range markup (no new component, no markup/API changes) in four thumb concepts × four themes. Drag a thumb, click the track, or focus a thumb and use Arrows / Home / End / PageUp / PageDown. Each variant shows a horizontal and a vertical slider.

  • Build themes first: npm run sass (generates packages/*/dist/all.css), then serve the repo root, e.g. npx http-server . -p 8080 → /experiments/rangeslider-thumbs/.
